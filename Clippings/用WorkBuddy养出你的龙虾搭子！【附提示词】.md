第一招：让龙虾了解你

因为龙虾刚装好的时候，它对你一无所知，

![图片](data:image/svg+xml,%3C%3Fxml version='1.0' encoding='UTF-8'%3F%3E%3Csvg width='1px' height='1px' viewBox='0 0 1 1' version='1.1' xmlns='http://www.w3.org/2000/svg' xmlns:xlink='http://www.w3.org/1999/xlink'%3E%3Ctitle%3E%3C/title%3E%3Cg stroke='none' stroke-width='1' fill='none' fill-rule='evenodd' fill-opacity='0'%3E%3Cg transform='translate(-249.000000, -126.000000)' fill='%23FFFFFF'%3E%3Crect x='249' y='126' width='1' height='1'%3E%3C/rect%3E%3C/g%3E%3C/g%3E%3C/svg%3E)

所以第一步，你得让它了解你。

我准备了一个模板，大家可以参考。

```
我叫小王，在杭州做运营，xxxx，今年个人成长目标是xxx，职业目标是做出xxx。
我希望你记住这个目标，在以后的协作中，都可以帮我想想这件事是不是在让我离目标更近。
另外，你也可以主动给我提建议，帮助我尽快的达到目标。 把这些写进你的长期记忆里。
```

它的好处是让你在低头看路，埋头干活的同时，也有一只虾在客观地帮你想着阶段性的北极星。

以终为始 ～

第二招：吾日三省吾身

那当龙虾对你有了基本了解，就可以效仿老祖宗的成长秘诀，吾日三省吾身！

我们可以利用WorkBuddy的定时任务功能，设置早、中、晚三个任务。

你只需要把提示词发给它，它就会自己到点自动执行。

![图片](data:image/svg+xml,%3C%3Fxml version='1.0' encoding='UTF-8'%3F%3E%3Csvg width='1px' height='1px' viewBox='0 0 1 1' version='1.1' xmlns='http://www.w3.org/2000/svg' xmlns:xlink='http://www.w3.org/1999/xlink'%3E%3Ctitle%3E%3C/title%3E%3Cg stroke='none' stroke-width='1' fill='none' fill-rule='evenodd' fill-opacity='0'%3E%3Cg transform='translate(-249.000000, -126.000000)' fill='%23FFFFFF'%3E%3Crect x='249' y='126' width='1' height='1'%3E%3C/rect%3E%3C/g%3E%3C/g%3E%3C/svg%3E)

早上：梳理

你可以直接把这段发给它：

```
帮我建一个每天早上8点的定时任务，内容是：
1. 搜索今天的AI行业新闻，帮我筛选3条最重要，形成摘要发给我，并且给我一些选题建议
2. 列出我今天的待办事项，按优先级排好
3. 你自己想一想，今天能主动帮我做什么，提1-2个建议
把这个任务建好，以后每天自动执行，需要我补充什么信息，可以向我提问
```

当然，如果你不关心AI新闻，换成股市动态、政治新闻、英语资讯、考公热点，都可以，改改第一条就好~

效果就是，你就像个老板一样，每天早上打开微信，就收到了助理给你整理的新闻简报、日程安排、以及它主动要为你做的事。

中午：对齐

那到了中午，龙虾还可以帮你做一次进度检查和提醒。你可以直接把这段发给它：

```
再帮我建一个每天中午12点的定时任务：
回顾一下我今天早上安排的待办事项，看看完成了多少，提醒我下午还有哪些要做的。
如果发现我上午效率不高，给我一点建议。
```

相当于小助理又来说“秋总，您上午的工作怎么样了，下午还有个会，如果上午有卡点，要不要交给我来做”！

![图片](data:image/svg+xml,%3C%3Fxml version='1.0' encoding='UTF-8'%3F%3E%3Csvg width='1px' height='1px' viewBox='0 0 1 1' version='1.1' xmlns='http://www.w3.org/2000/svg' xmlns:xlink='http://www.w3.org/1999/xlink'%3E%3Ctitle%3E%3C/title%3E%3Cg stroke='none' stroke-width='1' fill='none' fill-rule='evenodd' fill-opacity='0'%3E%3Cg transform='translate(-249.000000, -126.000000)' fill='%23FFFFFF'%3E%3Crect x='249' y='126' width='1' height='1'%3E%3C/rect%3E%3C/g%3E%3C/g%3E%3C/svg%3E)

Very nice！

晚上：复盘（最关键）

不过，晚上这一波才是精华，

```
再建一个每天晚上9点半的定时任务，内容是：
1. 对我今天的任务完成情况做一个复盘，哪些完成了，哪些没完成，效率如何
2. 你自己今天在帮我做事的过程中，犯了什么错、学到了什么，给出你的成长日报
3. 根据每天我们的对话，建一个主人档案，每天我的状态、情绪怎么样、行为模式、有什么缺点，帮助我客观的理解自己
4. 询问并跟我一起梳理明天要做的事，存到每日todo里，用于早上告诉我
```

这一步的效果，相当于你有了一个客观的视角，每天帮你观察自己。过一个月回头看，你会清楚地看到自己的变化~

我自己还额外加了一个任务：每天晚上给我讲一个科幻类的睡前故事。

你也可以每天让它推一个儿童故事，讲给孩子听～

第三招：沉淀经验，变成技能

第三招，也是我觉得最"邪修"的一招，

让龙虾帮你把看到的、做过的，全都变成可复用的经验。

看到好东西直接丢给它！比如你刷到一篇特别好的文章《如何高效沟通》，

![图片](data:image/svg+xml,%3C%3Fxml version='1.0' encoding='UTF-8'%3F%3E%3Csvg width='1px' height='1px' viewBox='0 0 1 1' version='1.1' xmlns='http://www.w3.org/2000/svg' xmlns:xlink='http://www.w3.org/1999/xlink'%3E%3Ctitle%3E%3C/title%3E%3Cg stroke='none' stroke-width='1' fill='none' fill-rule='evenodd' fill-opacity='0'%3E%3Cg transform='translate(-249.000000, -126.000000)' fill='%23FFFFFF'%3E%3Crect x='249' y='126' width='1' height='1'%3E%3C/rect%3E%3C/g%3E%3C/g%3E%3C/svg%3E)

别收藏了，直接发给龙虾，然后说：

```
帮我分析总结这篇文章的核心方法，沉淀成一个文档。
然后做成一个skill，以后我问你沟通相关的问题，你就按这套方法给我支招。
```

这样做的效果是：别人的经验，直接变成了你和龙虾的能力。

下次你要沟通，它给你的建议就不是泛泛而谈，而是基于那篇文章里的具体方法。

![图片](data:image/svg+xml,%3C%3Fxml version='1.0' encoding='UTF-8'%3F%3E%3Csvg width='1px' height='1px' viewBox='0 0 1 1' version='1.1' xmlns='http://www.w3.org/2000/svg' xmlns:xlink='http://www.w3.org/1999/xlink'%3E%3Ctitle%3E%3C/title%3E%3Cg stroke='none' stroke-width='1' fill='none' fill-rule='evenodd' fill-opacity='0'%3E%3Cg transform='translate(-249.000000, -126.000000)' fill='%23FFFFFF'%3E%3Crect x='249' y='126' width='1' height='1'%3E%3C/rect%3E%3C/g%3E%3C/g%3E%3C/svg%3E)

以此类推，好文章、好书、好视频、好教程，看到就丢给它，你的龙虾会越来越强，你也会越来越强。

第三招：沉淀经验

除了吸收别人的经验，你跟龙虾一起做过的事，也会自动变成方法论。

举个例子：你是做运营的，每次让龙虾帮你写文案，你会说"这个太硬广了"、“这个要这样”，“那个要那样”。

![图片](data:image/svg+xml,%3C%3Fxml version='1.0' encoding='UTF-8'%3F%3E%3Csvg width='1px' height='1px' viewBox='0 0 1 1' version='1.1' xmlns='http://www.w3.org/2000/svg' xmlns:xlink='http://www.w3.org/1999/xlink'%3E%3Ctitle%3E%3C/title%3E%3Cg stroke='none' stroke-width='1' fill='none' fill-rule='evenodd' fill-opacity='0'%3E%3Cg transform='translate(-249.000000, -126.000000)' fill='%23FFFFFF'%3E%3Crect x='249' y='126' width='1' height='1'%3E%3C/rect%3E%3C/g%3E%3C/g%3E%3C/svg%3E)

那我们希望每一次的反馈，他都能记住，帮你沉淀成一个文案方法笔记本。

那我们可以让他永久的记住这个规则

```
这是一个永久的硬性要求：每次让你写运营的文案，我所对你提出的所有要求，
你看到后先不要修改，先理解这些要求，并且沉淀到我们的文案方法笔记里面去，
然后每一次帮我写的时候，都要符合笔记当中的所有要求。
```

时间一长，你都不用再反复说要求了，它出来的东西就会越来越接近你想要的

不知不觉中你就攒出了自己专属的标准和SOP！巧妙建立专属skill ～
