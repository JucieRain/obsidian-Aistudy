# AI 驱动的 PPT 工作流：女娲 Skill + PPT Director

> 原文链接：https://mp.weixin.qq.com/s/WB5SiBxIZn_v8XK5af-uJw

核心思路：用 AI 做 PPT，先蒸馏受众，再生成表达。全程在 Claude Code 中完成——女娲负责"懂人"，Director 负责"造 PPT"，达尔文负责"打磨"。

## 一、前置条件

| 工具 | 用途 | 安装/添加指令 |
|------|------|---------------|
| Claude Code | 统一工作台 | – |
| Python 3.8+ | 运行 PPT 生成脚本 | `pip install python-pptx` |
| 女娲.skill | 认知蒸馏（受众/评审） | `npx skills add alchaincyf/nuwa-skill` |
| PPT Director.skill | PPT 导演全流程调度 | `npx skills add hermess/ppt-director` |
| 达尔文.skill（可选） | 内容打磨优化 | `npx skills add alchaincyf/darwin-skill` |

## 二、完整工作流程（7 阶段）

### 阶段 1：受众蒸馏（女娲）

从"凭感觉猜"变为"基于模型精确生产"。女娲并行调度 6 个 Agent：
1. 著作 Agent — 调研著作、文章、公开讲话
2. 对话 Agent — 分析对话风格、提问方式、思维习惯
3. 表达 Agent — 提炼常用表达、比喻、价值判断方式
4. 批评 Agent — 找出常见的否定模式、反感的事物
5. 决策 Agent — 梳理决策框架、权重分配
6. 时间线 Agent — 追踪认知演变和立场变化

完成后交叉验证，输出 .skill.md 文件。

使用方法：
- 情况A（知道具体是谁）：`用女娲蒸馏一个"[具体人名]"`
- 情况B（只知道角色）：`用女娲蒸馏一个"[角色类型]"的认知模型`
- 情况C（有场景约束）：`用女娲蒸馏：角色：[XX]，场景：[XX]，他的决策模型是什么？`

### 阶段 2：评审专家蒸馏（女娲）

| 维度 | audience-card（受众卡） | reviewer-card（评审卡） |
|------|-------------------------|--------------------------|
| 回答的问题 | 他想听什么？ | 他会挑什么毛病？ |
| 视角 | 接收者视角 | 审查者视角 |
| 用途 | 决定内容选什么、排什么序 | 决定逻辑够不够硬、表达够不够精准 |

推荐评审专家类型：
- 政府汇报：袁家军/省级领导（数据闭环检查、抓手逻辑检查）
- 融资 BP：沈南鹏/具体投资人（商业逻辑检查、否决点预判）
- 技术方案：行业 CTO（技术可行性检查、架构合理性）
- 产品提案：俞军/产品大师（用户价值检查、需求真伪判断）
- 演讲设计：Nancy Duarte（叙事结构检查、视觉原则检查）

### 阶段 3：PPT Director 判断阶段 + 选择路径

内置 5 个阶段（A→E），Director 自动判断当前处于哪一阶段：

| 阶段 | 判断依据 | Director 做什么 |
|------|----------|-----------------|
| A 灵感激发 | 只有一个主题/想法 | 发散思路、确认受众、初步规划 |
| B 内容打磨 | 有思路或原始材料 | 生成观点型大纲、标准交付文档 |
| C 视觉定义 | 已有标准交付文档 | 页型分配、风格映射 |
| D 代码生成 | 视觉定义已完成 | 生成 python-pptx 代码，输出 .pptx |
| E 迭代优化 | 已有 PPT 初稿 | 三重评审挑毛病，输出修改清单 |

### 阶段 4：内容规划（Director B 阶段）

核心公式：`受众关注什么 × 专家会怎么审 × 你有什么素材 = 每页放什么`

规则：
- 观点型标题（如"三年改革让办事时间缩短87%"）
- 每页 ≤3 个要点
- 前 3 页必须抓住注意力
- 证据链完整：每个观点配数据/案例
- 页型映射：17 种标准页型

默认风格卡（蓝色汇报）：深蓝 #003366、科技蓝 #0066CC、活力橙 #FF6600、浅灰背景 #F5F7FA

17 种标准页型示例：T01封面、T04纯文字观点、T05数据图表、T06对比页、T10数字突出、T17总结页

### 阶段 5：达尔文优化（可选但推荐）

适用于重要领导汇报、融资 BP、公开大会演讲。内部沟通 PPT 通常不需要。

### 阶段 6：三重评审关卡（Director E 阶段）

PPT 初稿生成后，Director 内置三重评审：
1. 受众视角评审（基于 audience-card）：改不改无所谓，是改善建议
2. 专家视角评审（基于 reviewer-card）：必须改，不改过不了关
3. 表达优化评审（基于 best-practices）：改了更专业

### 阶段 7：内容 + 视觉迭代

修改逻辑或数据 → 改标准交付文档 → 重新生成代码 → 输出新 .pptx

修改视觉版式 → 改 python-pptx 代码 → 只改视觉不改内容

## 三、核心创新：认知蒸馏

传统方法："这个受众大概喜欢什么风格？"→ 凭感觉猜

本方法："用女娲蒸馏 XX 的认知模型"→ 生成 audience-card.md 和 reviewer-card.md → PPT 内容基于模型精确生产

核心价值：从"大概感觉"到"精确模型"，一次蒸馏，终身可用。
