# WorkBuddy 官网

> 腾讯 WorkBuddy 官方网站，国产龙虾下载入口

## 官网地址

**下载页面**: https://www.codebuddy.cn/work/

## 产品定位

根据官方介绍，WorkBuddy 是：
- 腾讯开发的国产 AI Agent（龙虾）
- 专为普通白领设计
- 门槛最低的龙虾工具

## 核心特色

| 特色 | 说明 |
|-----|------|
| **微信集成** | 一键扫码，微信直接控制电脑 |
| **国产模型** | 内置多款国产模型，无需配置API |
| **专家模式** | 140+腾讯内部专家SOP封装 |
| **定时任务** | 内置早中晚任务模板 |
| **免费额度** | 注册送5000 credits |

## 安装方式

1. 访问官网 https://www.codebuddy.cn/work/
2. 点击下载按钮
3. 双击安装包安装
4. 打开软件即可使用

## 微信连接步骤

最新版支持微信 Clawbot：

1. 打开 WorkBuddy 软件
2. 点击「连接微信clawbot」
3. 扫码授权
4. 在微信给龙虾发消息、语音、图片

## 适用人群

- 普通白领
- 对命令行有恐惧感的用户
- 需要微信远程控制的用户
- 不想折腾配置的用户
