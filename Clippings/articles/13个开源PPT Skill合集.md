# PPT 自由来了！13 个开源 Skill 一次收齐

> 原文链接：https://mp.weixin.qq.com/s/WpqeJK3h3XN6OyZubPQmww

四象限定位：先分清要「能改」还是「好看」，要「交付文件」还是「现场演讲」。

## 类型一：原生可编辑 PPTX（4个）

1. **PPT Master** — 生成真实 PowerPoint 形状，支持演讲备注转旁白、跟随模板。Star 3.1万
2. **pptx-from-layouts-skill** — 从 Markdown 生成，用 slide master layouts 符合企业模板
3. **Huashu Design** — 面向 Agent 的视觉内容生成，覆盖幻灯片/动画/原型/信息图。Star 1.9万
4. **Fergana-Labs PowerPoint Skill** — Node.js 操作 PPT，支持文本/表格/图表/图片

## 类型二：HTML 演示（3个）

5. **Frontend Slides** — coding agent 用，可从零生成 HTML 或转换 PPTX。Star 2.3万
6. **Guizang PPT Skill** — 单文件 HTML 横向翻页，电子杂志风+瑞士国际主义
7. **HTML PPT Skill** — 组件完整：主题/布局/动画/演讲者模式/计时器

## 类型三：图片式卡片（2个）

8. **Baoyu Slide Deck** — 文章→大纲→单页图片，可合并 PPTX，适合小红书/朋友圈
9. **gpt-image2-ppt-skills** — gpt-image-2 仿 PPTX 模板版式，快速套风格

## 类型四：平台与框架（4个）

10. **Presenton** — 开源 AI Presentation Generator，本地运行/API/Docker
11. **PPTAgent** — Agentic PowerPoint 框架，规划→生成→检查→反思
12. **Anything to NotebookLM** — 多源内容到多格式输出（PPT/NotebookLM/播客/思维导图）
13. **Composio awesome-claude-skills pptx** — PPTX 文件结构/模板/布局处理参考

## 非开源补充

Anthropic 官方 pptx Skill — 能力边界参考，proprietary 许可。
