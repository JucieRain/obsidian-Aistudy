# 30年哑巴英语，用ChatGPT练开口

> 原文链接：https://mp.weixin.qq.com/s/mAFW-k4OYXbTHcHHaSEZbw
> 作者：李大贝

## 核心观点

- 真正开口的第一把火不是自律，是**刚需**（去头马演讲俱乐部必须当众开口）
- ChatGPT 是英语平权工具：24小时陪练、不笑你、能接住任何水平的对话
- 最终必须去有真人观众的场合说出来

## 五步练法

1. 先找有话说的话题（不要宏大，选吃喝玩乐、工作、旅行）
2. 给 ChatGPT 写好陪练提示词
3. 独立空间，语音聊天键，大胆说（不管语法、时态、卡住）
4. 整理和记忆 GPT 给的地道表达，组合成自己想说的话
5. 找公开场合说出来（演讲俱乐部等）

## ChatGPT 英语陪练提示词

```
你是我的美式英语聊天伙伴，请用温柔、鼓励的方式陪我练口语。
我会用英文或中英文夹杂表达，你不要打断我。
每次只纠正一个最重要的问题，然后给我一个更自然的表达。
请像朋友一样继续问我问题。
```

## 关键心态

- 「面子是困住读书人的紧箍咒」
- 说错了又怎么样？卡住了又怎么样？
- 你的声音有价值，因为你有故事可讲
