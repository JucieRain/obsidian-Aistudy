# Claudian

> 把 Claude Code 嵌入 Obsidian 的插件，2.8k star

## 核心能力

- **侧边栏聊天**：在 Obsidian 内直接与 Claude 对话
- **内联编辑**：选中文字 + 快捷键，Claude 直接改写（diff 预览）
- **上下文感知**：自动附带当前笔记，`@` 提及其他文件
- **Skills 支持**：加载技能包扩展能力
- **MCP 支持**：接入外部工具和数据源
- **图片识别**：拖拽图片，Claude 分析

## 安装方式

1. **AI 自动安装**：告诉 Claude Code「安装 claudian 插件」
2. **手动安装**：下载插件放到 `.obsidian/plugins/claudian/`

## 与 cc-switch 配合

解决模型/API 问题：
- 一键切换到第三方中转或国产模型
- 支持 DeepSeek、Kimi、GLM、MiniMax 等
- 管理 MCP 和 Skills

## 实际应用

- **素材收集**：丢进去就行，不用整理
- **知识整理**：一句话让 AI 跨文档整理
- **跨文档关联**：AI 自动建双向链接
- **内联编辑**：选中就改，diff 预览
