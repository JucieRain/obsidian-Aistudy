# Obsidian Web Clipper

> Obsidian 官方浏览器插件，剪藏网页到 Markdown

## 核心功能

- 一键剪藏网页文章
- 自动转换为 Markdown 格式
- 可自定义模板和 frontmatter
- 支持多种浏览器（Chrome、Firefox、Edge）

## 下载地址

https://obsidian.md/clipper

## 配置建议

- 默认剪藏目录：`Clippings/`（与 Web Clipper 默认名称一致）
- 可自定义 frontmatter 模板
- 绑定快捷键下载图片到本地

## 在 LLM Wiki 中的作用

素材收集的核心工具：
- 看到好文章直接裁剪进素材目录
- 后续 AI 自动处理录入
- 不需要手动整理格式
