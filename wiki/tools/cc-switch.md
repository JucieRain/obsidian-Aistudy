# cc-switch

> Claude Code 配置管理桌面应用，开源项目

## 核心功能

1. **一键切换模型/API**：从官方 API 切到第三方中转或国产模型
2. **MCP 与 Skills 管理**：可视化界面管理 MCP 服务器和技能
3. **提示词管理**：管理多套系统提示词，内置测速

## 支持的模型

国产兼容模型：
- DeepSeek
- Kimi
- GLM
- MiniMax

## 解决的问题

- 官方 API 价格贵
- 国内网络访问有门槛
- 手动改配置文件麻烦
