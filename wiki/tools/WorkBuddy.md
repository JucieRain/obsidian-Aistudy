# WorkBuddy

> 腾讯开发的国产龙虾，给普通白领打造的Work Buddy，支持微信集成

## 工具概览

| 项目信息 | |
|---------|---------|
| **开发者** | 腾讯 |
| **定位** | 给普通白领打造的国产自研龙虾 |
| **特色** | 微信集成、定时任务、经验沉淀、专家模式 |
| **官网** | https://www.codebuddy.cn/work/ |

## 核心功能

### 微信 Clawbot 集成

最新版支持微信连接，只需三步：
1. 点击「连接微信clawbot」
2. 扫码授权
3. 直接在微信给龙虾发消息、语音、图片

最离谱的特性：**微信直接控制电脑干活**。

### 国产模型内置

内置多款国产模型，聊天界面可直接切换：
- 注册送5000 credits
- 用好几天都没用完

### 专家模式

腾讯内部140+真人大咖实战经验封装：
- 约140个专家SOP
- 让腾讯团队帮你干活
- 覆盖直播电商、运营等多领域

**实测案例**：直播电商专家输出完整方案——平台建议、人群建议、价格带、人设方向、卖点梳理、排品策略、千川概念。

### 定时任务

支持早、中、晚三个定时任务：
- 早上：新闻简报 + 待办排序 + 主动建议
- 中午：进度检查 + 下午提醒 + 效率建议
- 晚上：复盘 + 龙虾成长日报 + 主人档案 + 明天待办

## 养成方法

### 第一招：让龙虾了解你

```markdown
我叫小王，在杭州做运营，xxxx，今年个人成长目标是xxx，
职业目标是做出xxx。
我希望你记住这个目标，在以后的协作中，都可以帮我想想
这件事是不是在让我离目标更近。
另外，你也可以主动给我提建议，帮助我尽快的达到目标。
把这些写进你的长期记忆里。
```

好处：低头干活时，有一只虾帮你想着阶段性北极星。以终为始。

### 第二招：吾日三省吾身

**早上任务提示词**：
```
帮我建一个每天早上8点的定时任务，内容是：
1. 搜索今天的AI行业新闻，帮我筛选3条最重要，形成摘要发给我
2. 列出我今天的待办事项，按优先级排好
3. 你自己想一想，今天能主动帮我做什么，提1-2个建议
把这个任务建好，以后每天自动执行
```

**中午任务提示词**：
```
再帮我建一个每天中午12点的定时任务：
回顾一下我今天早上安排的待办事项，看看完成了多少，
提醒我下午还有哪些要做的。如果发现我上午效率不高，给我一点建议。
```

**晚上任务提示词**（精华）：
```
再建一个每天晚上9点半的定时任务，内容是：
1. 对我今天的任务完成情况做一个复盘
2. 你自己今天在帮我做事的过程中，犯了什么错、学到了什么，给出你的成长日报
3. 根据每天我们的对话，建一个主人档案，记录我的状态、情绪、行为模式、缺点
4. 询问并跟我一起梳理明天要做的事，存到每日todo里
```

效果：每天早上微信一打开就进入状态，晚上在复盘中清晰结束。日积月累，你和虾都在进步。

### 第三招：沉淀经验，变成技能

看到好文章直接发给龙虾：

```
帮我分析总结这篇文章的核心方法，沉淀成一个文档。
然后做成一个skill，以后我问你相关的问题，
你就按这套方法给我支招。
```

效果：别人的经验变成你和龙虾的能力。

**案例**：运营文案反馈沉淀

```
这是一个永久的硬性要求：每次让你写运营的文案，
我所对你提出的所有要求，你看到后先不要修改，
先理解这些要求，并且沉淀到我们的文案方法笔记里面去，
然后每一次帮我写的时候，都要符合笔记当中的所有要求。
```

时间一长，攒出自己专属的标准和SOP。

## 实战效果

- 每天早上微信收到新闻简报、日程安排、主动建议
- 中午进度检查、下午提醒
- 晚上复盘、龙虾成长日报、主人档案
- 经验自动沉淀成Skill
- 专家模式输出完整业务方案

## 与其他龙虾对比

| 特性 | WorkBuddy | OpenClaw | Hermes Agent |
|-----|----------|----------|--------------|
| **微信集成** | ✅ 一键扫码 | 需配置 | 需配置 |
| **国产模型** | ✅ 内置多款 | 百炼为主 | 模型无关 |
| **专家SOP** | ✅ 140+真人封装 | 无 | 无 |
| **定时任务** | ✅ 内置 | 需配置Cron | 需配置Cron |
| **门槛** | ⭐ 最低 | 中等 | 中等 |
