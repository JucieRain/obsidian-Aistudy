## 安装方式

### 下载安装

1. 访问官网 https://www.codebuddy.cn/work/
2. 点击下载按钮
3. 双击安装包安装
4. 打开软件即可使用

### 微信连接

最新版支持微信Clawbot，只需三步：
1. 打开 WorkBuddy 软件
2. 点击「连接微信clawbot」
3. 扫码授权
4. 在微信给龙虾发消息、语音、图片

**最离谱的特性**：微信直接控制电脑干活。

## 核心功能

### 国产模型内置

内置多款国产模型，聊天界面可直接切换：
- 注册送5000 credits
- 用好几天都没用完
- 无需配置API密钥

### 专家模式

腾讯内部140+真人大咖实战经验封装：
- 约140个专家SOP
- 让腾讯团队帮你干活
- 覆盖直播电商、运营等多领域

**实测案例**：直播电商专家输出完整方案——平台建议、人群建议、价格带、人设方向、卖点梳理、排品策略、千川概念。

### 定时任务

支持早、中、晚三个定时任务：
- 早上：新闻简报 + 待办排序 + 主动建议
- 中午：进度检查 + 下午提醒 + 效率建议
- 晚上：复盘 + 龙虾成长日报 + 主人档案 + 明天待办

## 养成方法

### 第一招：让龙虾了解你

```markdown
我叫小王，在杭州做运营，xxxx，今年个人成长目标是xxx，
职业目标是做出xxx。
我希望你记住这个目标，在以后的协作中，都可以帮我想想
这件事是不是在让我离目标更近。
另外，你也可以主动给我提建议，帮助我尽快的达到目标。
把这些写进你的长期记忆里。
```

好处：低头干活时，有一只虾帮你想着阶段性北极星。以终为始。

### 第二招：吾日三省吾身

**早上任务提示词**：
```
帮我建一个每天早上8点的定时任务，内容是：
1. 搜索今天的AI行业新闻，帮我筛选3条最重要，形成摘要发给我
2. 列出我今天的待办事项，按优先级排好
3. 你自己想一想，今天能主动帮我做什么，提1-2个建议
把这个任务建好，以后每天自动执行
```

**中午任务提示词**：
```
再帮我建一个每天中午12点的定时任务：
回顾一下我今天早上安排的待办事项，看看完成了多少，
提醒我下午还有哪些要做的。如果发现我上午效率不高，给我一点建议。
```

**晚上任务提示词**（精华）：
```
再建一个每天晚上9点半的定时任务，内容是：
1. 对我今天的任务完成情况做一个复盘
2. 你自己今天在帮我做事的过程中，犯了什么错、学到了什么，给出你的成长日报
3. 根据每天我们的对话，建一个主人档案，记录我的状态、情绪、行为模式、缺点
4. 询问并跟我一起梳理明天要做的事，存到每日todo里
```

效果：每天早上微信一打开就进入状态，晚上在复盘中清晰结束。日积月累，你和虾都在进步。

### 第三招：沉淀经验，变成技能

看到好文章直接发给龙虾：

```
帮我分析总结这篇文章的核心方法，沉淀成一个文档。
然后做成一个skill，以后我问你相关的问题，
你就按这套方法给我支招。
```

效果：别人的经验变成你和龙虾的能力。

**案例**：运营文案反馈沉淀

```
这是一个永久的硬性要求：每次让你写运营的文案，
我所对你提出的所有要求，你看到后先不要修改，
先理解这些要求，并且沉淀到我们的文案方法笔记里面去，
然后每一次帮我写的时候，都要符合笔记当中的所有要求。
```

时间一长，攒出自己专属的标准和SOP。

## Windows 安装指南

### 下载安装

1. 访问官网 https://www.codebuddy.cn/work/
2. 点击「立即下载」等待安装包下载
3. 双击安装包启动安装程序
4. 勾选「我同意此协议」→ 下一步
5. 选择安装路径 → 下一步
6. 确认开始菜单文件夹 → 下一步
7. 勾选「创建桌面快捷方式」→ 下一步
8. 点击「安装」→ 完成

### 登录

1. 启动 WorkBuddy，点击「登录」
2. 勾选《服务条款》与《隐私协议》
3. 使用微信扫码完成登录
4. 登录成功后即可开始使用

### 语言设置

点击左下角头像 → 语言 进行切换。

### 版本更新

点击左下角头像 → 检查更新，系统自动检测并升级。

### 使用场景

- **出门在外**：用手机让电脑处理文件

2. 点击「Claw 设置」

## WorkBuddy 小程序

WorkBuddy 微信小程序是移动端入口，支持云上模式和本机模式。

### 核心能力

- **多模态输入**：文字、语音、图片、文件
- **双模式执行**：
  - 云上模式：云端沙箱执行，无需依赖电脑
  - 本机模式：远程操控桌面端 WorkBuddy
- **任务管理**：创建、查看、追问、中断
- **技能扩展**：通过 SkillHub 安装技能包

### 进入小程序

**扫码进入**：微信扫描小程序码

**搜索进入**：
1. 微信下拉进入「小程序」搜索栏
2. 搜索「腾讯 WorkBuddy」
3. 点击进入

面向职场通用工作场景：
- 文档生成：工作报告、技术文档、README
