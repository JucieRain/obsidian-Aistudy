# 飞书

> 字节跳动推出的企业协作平台，集成 IM、文档、日历、邮件等能力

## 核心特性

- **一体化协作**：聊天、文档、日历、邮件、多维表格整合
- **AI 能力**：内置 AI 助手，支持文档生成、会议总结
- **开放平台**：提供 API、CLI，支持 AI Agent 接入
- **企业级**：权限管理、审批流程、知识库

## AI Agent 接入方式

### 飞书 CLI

官方开源的 CLI 工具，给 AI Agent 操作飞书的能力：
- **GitHub**：https://github.com/larksuite/cli
- **能力**：读消息、查日历、写文档、建表格、发邮件
- **身份支持**：用户身份 + 应用身份

### 接入场景

| 场景 | CLI 能力 |
|-----|---------|
| 会议总结 | 读取会议记录 → 生成文档 |
| 智能约会 | 跨时区多人日程协调 |
| 群聊整理 | 消息汇总、任务提取 |
| 邮件分类 | 未读邮件智能处理 |

### OpenClaw 集成

- OpenClaw 飞书官方插件即将内置 CLI 能力
- 支持扫码接入、手动配置两种方式
- 需要创建飞书应用，配置 App ID 和 App Secret

## 与 Hermes Agent 集成

- Hermes 支持 `[feishu]` extra 安装
- 需配置用户白名单或配对码
- 支持私聊和群聊 @机器人
