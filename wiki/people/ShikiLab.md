## 核心贡献

### Obsidian CLI 基础使用教程

详细介绍如何用 Obsidian CLI + Claude Code 实现知识管理自动化：
- 开启 Obsidian CLI（v1.12+）
- 安装 Node.js 和 Claude Code
- 配置 MiniMax Coding Plan 替换模型
- 快速建立知识管理结构
- 批量整理旧笔记
- 常用操作存成指令反复调用

### CLI 配置要点

MiniMax Coding Plan 配置步骤：
- 创建 ~/.claude/settings.json
- 创建 ~/.claude.json
- 配置 ANTHROPIC_BASE_URL 和 API Key
- 替换模型为 MiniMax-M2.5

### 核心观点

**AI 接管笔记的方法彻底变天了**

配置好 CLI 后：
- 让 AI 进入仓库动手干活
- 不是复制粘贴内容给 AI，是让 AI 直接操作
- 批量处理、一键整理、指令复用
