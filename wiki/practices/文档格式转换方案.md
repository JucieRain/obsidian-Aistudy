# 文档格式转换方案

> DOCX ↔ Markdown 双向转换的实践方案，解决测试用例文档管理的核心痛点

---

## 一、问题背景

测试用例文档管理存在三大痛点：

| 痛点 | 说明 | 严重程度 |
|-----|------|---------|
| **格式不统一** | 约 100 份历史文档，DOCX + Excel 混杂 | 🔴 高 |
| **转换失真** | Markdown ↔ Word 转换时标题、表格、图片丢失 | 🔴 高 |
| **组网图处理** | 无法在 Markdown 中呈现，也无法从 Word 还原 | 🔴 高 |

---

## 二、工具调研结论

### 2.1 测试的工具

| 工具 | 开发者 | 定位 | Windows 支持 |
|-----|-------|------|-------------|
| **Pandoc** | John MacFarlane | 通用文档转换 | ✅ 完美 |
| **Docling** | IBM | 企业级文档处理 | ✅ 可运行 |
| **MarkItDown** | Microsoft | LLM 输入预处理 | ✅ 可运行 |
| **Marker** | Datalab | 高精度 PDF 转换 | ❌ DOCX 需 GTK 库 |
| **Quarto** | Quarto.org | 学术出版系统 | ✅ 可运行 |

### 2.2 效果对比

使用真实 DOCX 文档测试（含标题、表格、代码块、图片）：

| 工具 | 标题层级 | 代码块 | 图片处理 | 内网可用 | 推荐 |
|-----|---------|-------|---------|---------|------|
| **Pandoc** | ⚠️ 需后处理 | ⚠️ Grid table | ✅ **提取文件** | ✅ 完全离线 | ⭐⭐⭐⭐ |
| **Docling** | ❌ 变粗体 | ❌ 未识别 | ❌ 占位符 | ✅ 官方支持 | ⭐⭐ |
| **MarkItDown** | ❌ 变粗体 | ❌ 变表格 | ✅ base64 嵌入 | ✅ 离线 | ⭐⭐⭐ |
| **Marker** | ❌ 无法运行 | - | - | ❌ 需 GTK | ❌ |
| **Quarto** | ✅ 完美 | ✅ Mermaid→PNG | ✅ 自动处理 | ✅ 完全离线 | ⭐⭐⭐⭐⭐ |

### 2.3 关键发现

**标题丢失的根本原因**：

原文档使用「加粗文本」表示标题，而非 Word 正式标题样式（Heading 1/2/3）。Pandoc 只能识别标准 Word 样式。

---

## 三、最终方案

### 3.1 DOCX → Markdown（历史文档录入）

**推荐方案：Pandoc + 后处理脚本**

```bash
# 步骤 1：Pandoc 转换
pandoc input.docx -o output.md --extract-media=media/

# 步骤 2：后处理修复
python scripts/pandoc_postprocess.py output.md output_fixed.md
```

**后处理脚本功能**：

| 功能 | 说明 |
|-----|------|
| 修复标题层级 | `**标题**` → `## 标题` |
| 移除图片尺寸 | `{width="5.75in" height="3in"}` → 清理 |
| 清理多余空行 | 最多保留两个连续空行 |

**效果**：

- ✅ 标题层级正确
- ✅ 图片提取到独立文件夹（可替换、可编辑）
- ⚠️ 代码块/Grid table 需少量手动调整

### 3.2 Markdown → DOCX（测试用例输出）

**推荐方案：Quarto**

```bash
# 安装 Quarto
# Windows: winget install quarto

# 转换命令
quarto render input.md --to docx

# 使用自定义模板
quarto render input.md --to docx --reference-doc=template.docx
```

**Quarto 核心优势**：

| 功能 | 说明 |
|-----|------|
| **Mermaid → PNG** | 组网图自动转为图片嵌入 Word |
| **表格编号** | 自动生成「表 1」「表 2」 |
| **图片编号** | 自动生成「图 1」「图 2」 |
| **交叉引用** | `@fig-xxx` 自动链接到图片 |
| **自定义模板** | `reference-doc` 指定公司文档规范 |

### 3.3 组网图处理方案

| 场景 | 方案 | 说明 |
|-----|------|------|
| **新组网图** | Mermaid + Quarto | Markdown 原生，导出时自动转 PNG |
| **历史组网图** | Draw.io 手动重绘 | 保留 `.drawio` 源文件 + 导出 PNG |
| **逆向还原** | ❌ 无工具 | 目前无工具可从图片还原拓扑结构 |

## 四、完整工作流

```
┌─────────────────────────────────────────────────────────────┐
│                    文档转换工作流                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【历史文档录入】                                             │
│  DOCX → Pandoc → Markdown → 后处理脚本 → 入库               │
│                                                             │
│  【新文档创作】                                               │
│  Obsidian 写 Markdown + Mermaid → Quarto → 导出 DOCX        │
│                                                             │
│  【组网图】                                                   │
│  新图：Mermaid（Quarto 导出 PNG）                            │
│  历史图：Draw.io 重绘（保留源文件）                           │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
