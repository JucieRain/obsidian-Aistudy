# 工作日志模板

> 基于 Obsidian Properties + Dataview 的项目管理系统

---

## 一、日志模板格式

### 日常日志模板

```markdown
---
title: 日志 - YYYY-MM-DD
date: YYYY-MM-DD
type: daily-log
tags: [日志, 工作]
projects: []
status: active
---

# 日志 - YYYY-MM-DD

## 今日完成

- [x] 任务1 - [[项目A]]
- [x] 任务2 - [[项目B]]

## 今日待办

- [ ] 待办1
- [ ] 待办2

## 明日计划

- 计划1
- 计划2

## 阻塞/问题

- 问题描述 → 解决方案

## 备注

- 其他记录
```

### 项目日志模板

```markdown
---
title: 项目日志 - 项目名
project: 项目名
created: YYYY-MM-DD
updated: YYYY-MM-DD
status: active | paused | completed
priority: high | medium | low
deadline: YYYY-MM-DD
owner: 负责人
tags: [项目, 日志]
---

# 项目日志 - 项目名

> 项目概述一句话

---

## 项目信息

| 属性 | 值 |
|-----|---|
| **状态** | active |
| **优先级** | high |
| **截止日期** | YYYY-MM-DD |
| **负责人** | 名字 |
| **相关链接** | [[相关文档]] |

---

## 任务清单

### 高优先级

- [ ] 任务A @due:YYYY-MM-DD
- [ ] 任务B @due:YYYY-MM-DD

### 中优先级

- [ ] 任务C
- [ ] 任务D

### 已完成

- [x] 任务E @done:YYYY-MM-DD

---

## 进度记录

### YYYY-MM-DD

**完成**：
- 任务E 完成

**进度**：30%

**下一步**：任务A

---

## 里程碑

| 里程碑 | 目标日期 | 状态 |
|-------|---------|------|
| M1: 需求确认 | YYYY-MM-DD | ✅ 完成 |
| M2: 设计完成 | YYYY-MM-DD | 🔄 进行中 |
| M3: 开发完成 | YYYY-MM-DD | ⏳ 待开始 |
| M4: 上线 | YYYY-MM-DD | ⏳ 待开始 |

---

## 风险与问题

| 问题 | 影响 | 状态 | 解决方案 |
|-----|-----|------|---------|
| 技术难点A | 中 | 已解决 | 采用方案X |
| 资源不足 | 高 | 进行中 | 申请增援 |

---

## 参见

- [[相关文档1]]
- [[相关文档2]]

---

*最后更新：YYYY-MM-DD*
```

## 二、Dataview 查询模板

### 查看所有活跃项目

```dataview
TABLE status, priority, deadline, owner
FROM #项目
WHERE status = "active"
SORT deadline ASC
```

### 查看今日待办

```dataview
TASK
FROM #日志
WHERE date = date(today) AND !completed
```

### 查看本周进度

```dataview
TABLE progress, deadline
FROM #项目
WHERE deadline >= date(today) AND deadline <= date(today) + dur(7 days)
SORT deadline ASC
```

### 查看阻塞问题

```dataview
TABLE problem, status, solution
FROM #项目
WHERE contains(file.content, "阻塞") OR contains(file.content, "问题")
```

## 三、使用说明

### 1. 创建日常日志

1. 在 `Journal/` 目录创建 `YYYY-MM-DD.md`
2. 使用日常日志模板
3. 记录今日完成、待办、问题

### 2. 创建项目日志

1. 在 `wiki/practices/` 创建项目页面
2. 使用项目日志模板
3. 定期更新进度

### 3. 查看项目总览

使用 Dataview 查询：
- 活跃项目列表
- 临近截止日期项目
- 待办任务汇总

## 四、最佳实践

### 日志频率

- **日常日志**：每日记录
- **项目日志**：每周更新进度

### 标签规范

| 标签 | 用途 |
|-----|------|
| `#日志` | 日常日志 |
| `#项目` | 项目日志 |
| `#任务` | 独立任务 |
| `#阻塞` | 有阻塞问题 |

### 状态流转

```
⏳ 待开始 → 🔄 进行中 → ✅ 完成
           ↓
           ❌ 暂停/取消
```
