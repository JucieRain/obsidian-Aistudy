## 二、Hermes Agent 模型配置

### 配置文件位置

- 配置目录：`~/.hermes/`
- 主配置：`config.yaml`（非敏感配置）
- 密钥文件：`.env`（API Keys）

### 配置方式

**方式 A：交互式配置**

```bash
hermes model
```

**方式 B：命令行设置**

```bash
# 设置提供商和默认模型
hermes config set model.provider alibaba
hermes config set model.default qwen3.5-plus

# 设置 API Key
hermes config set DASHSCOPE_API_KEY "你的密钥"
```

### 支持的提供商

| 提供商 | 环境变量 | 配置示例 |
|-------|---------|---------|
| **Alibaba/DashScope** | `DASHSCOPE_API_KEY` | `model.provider: alibaba` |
| **OpenRouter** | `OPENROUTER_API_KEY` | 密钥以 `sk-or-v1-` 开头 |
| **OpenAI** | `OPENAI_API_KEY` | `model.provider: openai` |

### DashScope 详细配置

```bash
# 设置阿里云通义
hermes config set model.provider alibaba
hermes config set model.default qwen3.5-plus
hermes config set DASHSCOPE_API_KEY "你的密钥"

# 可选：覆盖 Base URL
echo 'DASHSCOPE_BASE_URL=https://coding.dashscope.aliyuncs.com/v1' >> ~/.hermes/.env
```

### 辅助模型配置

Vision、网页摘要等辅助能力需在 `config.yaml` 中配置 `auxiliary.*`：

```yaml
auxiliary:
  vision:
    provider: alibaba
  web_extract:
    provider: alibaba
```

### 常见问题

| 问题 | 原因 | 解决方案 |
|-----|------|---------|
| 401 错误 | 模型路由错，跑到 OpenRouter | 固定 `model.provider` 和 `model.default` |
| 网关运行但不回复 | 用户白名单拦截 | `hermes config set GATEWAY_ALLOW_ALL_USERS true` |
| av/cython 构建失败 | 多媒体依赖可选 | 使用最小安装 `pip install -e ".[feishu]"` |

## 三、OpenClaw 模型配置

### 配置方式

OpenClaw 通过阿里云轻量应用服务器控制台配置：

**系统推荐**：下拉选择百炼 API Key（按地域推荐）

**手动输入**：填写 API Key + 选择地域

### 支持的 API Key 类型

| 类型 | 特点 | 适用场景 |
|-----|------|---------|
| **Coding Plan API Key** | 固定月费，月度额度，超时不计费 | 成本可控，推荐 |
| **按量计费 API Key** | 标准 Token 计费 | 高频使用 |

### Coding Plan 支持模型

- `qwen3.5-plus`
- `kimi-k2.5`
- `MiniMax-M2.5`
- `glm-5`

### 配置步骤

1. 轻量应用服务器控制台 → 应用详情
2. 执行「配置 OpenClaw」
3. 选择 API Key 类型并输入密钥
4. 访问 WebUI 验证

## 四、Claude Code 模型配置

### 配置文件位置

| 系统 | 路径 |
|-----|------|
| **Windows** | `C:\Users\用户名\.claude\settings.json` |
| **macOS/Linux** | `~/.claude/settings.json` |

### 配置格式

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "sk-你的API令牌",
    "ANTHROPIC_BASE_URL": "https://api.anthropic.com",
    "ANTHROPIC_MODEL": "claude-sonnet-4-5-20250929",
    "ANTHROPIC_SMALL_FAST_MODEL": "claude-haiku-4-5-20251001"
  }
}
```

### 配置项说明

| 配置项 | 说明 |
|-------|------|
| `ANTHROPIC_AUTH_TOKEN` | API 认证令牌，以 `sk-` 开头 |
| `ANTHROPIC_BASE_URL` | API 服务地址（官方或中转） |
| `ANTHROPIC_MODEL` | 主模型 ID |
| `ANTHROPIC_SMALL_FAST_MODEL` | 快速小模型 ID |

### 第三方中转配置

使用中转服务时，只需修改 `ANTHROPIC_BASE_URL`：

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "sk-中转密钥",
    "ANTHROPIC_BASE_URL": "https://中转服务地址",
    "ANTHROPIC_MODEL": "claude-sonnet-4-5-20250929"
  }
}
```

### 常见问题

| 问题 | 解决方案 |
|-----|---------|
| Invalid API Key | 检查密钥格式、重启终端 |
| offline 状态 | 不影响使用，仅表示无法连接 Google |
| fetch failed | 检查网络代理配置 |

## 五、Claudian 模型配置

Claudian 底层依赖 Claude Code CLI，**继承 Claude Code 的配置**。

### 配置方式

1. 先配置 Claude Code（见上方）
2. 安装 Claudian 插件
3. Claudian 自动读取 Claude Code 配置

### 安装方式

**AI 自动安装**：
```
"帮我为这个文件所在的 Obsidian 库安装 claudian 插件并打开"
```

**手动安装**：
下载插件放到 `.obsidian/plugins/claudian/`

### 与 cc-switch 配合

使用 cc-switch 切换模型后，Claudian 底层自动使用新配置。

## 六、cc-switch 配置管理

### 功能

1. **一键切换模型/API**：官方 API → 第三方中转 → 国产模型
2. **MCP 与 Skills 管理**：可视化界面管理
3. **提示词管理**：多套系统提示词 + 测速

### 支持的国产模型

- DeepSeek
- Kimi
- GLM
- MiniMax

### 使用方法

1. 下载打开 cc-switch
2. 添加 API 配置（密钥 + Base URL）
3. 点击切换模型
4. Claude Code / Claudian 自动使用新配置

### 项目地址

GitHub：https://github.com/farion1231/cc-switch
