# OpenClaw 阼云部署

> 阼云轻量应用服务器一键部署OpenClaw官方指南

## 计费说明

### 服务器费用

轻量应用服务器费用，参见阿里云计费概述。

### 模型调用费用

| 计费方式 | 说明 | 推荐场景 |
|---------|------|---------|
| **Coding Plan套餐** | 固定月费，提供月度请求额度 | 推荐！避免超预期费用 |
| **按Token计费** | 按实际用量计费 | 需开启「免费额度用完即停」 |

**Coding Plan支持模型**：
- `qwen3.5-plus`
- `kimi-k2.5`
- `MiniMax-M2.5`
- `glm-5`

详细模型列表参见 Coding Plan概述。

**重要**：首次开通阿里云百炼自动发放新人免费额度，消耗完默认按量计费，建议开启「免费额度用完即停」功能。

## 部署步骤

### 1. 购买服务器

购买预装OpenClaw的轻量应用服务器：
- 内存必须2GiB及以上
- 默认地域：北京
- 默认时长：12个月

**注意**：已购买服务器可通过「重置系统」部署OpenClaw，会清除系统盘数据，请备份。

### 2. 端口放通

在控制台「应用详情」→「端口放通」→「执行命令」。

**重要**：
- OpenClaw初始化使用随机端口（防恶意扫描）
- 端口放通使服务暴露公网，支持一键关闭WebUI公网访问

### 3. 配置百炼API Key

在「应用详情」→「配置OpenClaw」→「执行命令」。

支持两种API Key：
- **Coding Plan套餐专属API Key**（推荐）
- **按Token计费API Key**

选择模型后点击下一步。

**注意**：手动输入API Key时，确保地域与API Key对应地域一致。

### 4. 获取WebUI地址

在「应用详情」→「访问Web UI面板」→「获取地址」。

### 5. 查看Token（可选）

在「应用详情」→「基础配置」→「查看Token」。

**警告**：请勿泄露包含Token的完整URL，任何持有此链接的人都能绕过登录验证获得管理员权限。

## 常见问题

### 重启OpenClaw网关

连接中断或服务不可用时，在「应用详情」→「基础配置」→「重启OpenClaw网关」→「执行命令」。

### 查看端口号

在「应用详情」→「基础配置」→「查看端口」→「执行命令」。

### 更换模型

在「应用详情」→「模型配置」→删除默认模型→下拉选择百炼模型。

支持手动输入模型名，模型Code可在百炼模型广场查询。

### 开启/关闭WebUI公网访问

在「应用详情」→「基础配置」→「公网访问」→「开启/关闭」。

### API Key不识别

系统自动检测离服务器最近地域的百炼接入点：

| 服务器地域 | 推荐API Key地域 |
|----------|---------------|
| 中国内地 | 华北2（北京） |
| 美国及欧洲 | 美国（弗吉尼亚） |
| 中国香港及其他亚洲 | 新加坡 |

### 默认模型版本说明

| 版本 | 默认模型 |
|-----|---------|
| **2026.2.26** | qwen3.5-plus（最新） |
| **2026.2.3/2.9** | qwen3-max-2026-01-23 + qwen3-vl-plus |
| **2026.1.27-beta.1** | 2026-01-31后：qwen3-max；之前：qwen-vl-plus |
