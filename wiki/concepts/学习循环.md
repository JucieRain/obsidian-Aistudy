# 学习循环

> 自改进 Agent 的核心机制——Agent 自己给自己造缰绳，缰绳会自己长大

## 定义

学习循环（Learning Loop）是 Hermes Agent 的核心创新，将「人类手动维护规则」变成「Agent 自动从反馈中学习」的闭环机制。

与传统 AI 记忆的区别：
- **传统 AI**：记忆是对话记录的堆积（录像带，越来越长最终溢出）
- **学习循环**：记忆是经验的蒸馏（笔记本，可以一直用下去）

> — Clippings/papers/Hermes Agent 从入门到精通.pdf, §03

## 五环节闭环

```
策划记忆 → 创建 Skill → Skill 自改进 → FTS5 召回 → 用户建模
```

| 环节 | 职责 | 触发时机 | 说明 |
|-----|------|---------|------|
| **策划记忆** | 主动决定哪些信息值得记住 | 每轮对话结束 | 不是被动存储，是主动策划 |
| **创建 Skill** | 将解决方案提炼成可复用能力 | 完成复杂任务后 | 存到 ~/.hermes/skills/ |
| **Skill 自改进** | 根据反馈自动优化 Skill 文件 | 使用 Skill 过程中 | 不等人维护，自己进化 |
| **FTS5 召回** | 按需检索历史记忆 | 新对话开始时 | 不全量加载，精准检索 |
| **用户建模** | 推导用户偏好、习惯、目标 | 每次对话结束 | Honcho 辩证建模 |

五个环节之间有因果关系：
- 记忆提供了 Skill 创建的素材
- Skill 在使用中积累反馈触发自改进
- FTS5 让历史经验被精准召回
- 用户建模把这些碎片拼成完整画像

> — Clippings/papers/Hermes Agent 从入门到精通.pdf, §03

## 飞轮加速效应

五环节单独看都不算新鲜，但 Hermes 的创新在于把它们组成闭环：

```
记忆喂养 Skill → Skill 使用中产生新记忆 → 新记忆触发 Skill 改进
→ 改进后 Skill 产生更好结果 → 更好结果让用户建模更准确
→ 更准确画像让下一次记忆策划更有针对性
```

这是一个正反馈循环。用得越多，每个环节都在变强，而且是同时变强。

> — Clippings/papers/Hermes Agent 从入门到精通.pdf, §03

## 与 Mitchell Hashimoto 方式的对比

Mitchell Hashimoto（Terraform 创造者）的做法：
- 每次 Agent 犯错，就在 CLAUDE.md 里加一条规则
- 几周下来，CLAUDE.md 变成非常详细的项目规范
- Agent 从什么都不知的新人，变成了解所有暗规则的老手

Hermes 把这个过程自动化了：

| 维度 | Mitchell 方式（手动） | Hermes 方式（自动） |
|-----|---------------------|-------------------|
| 规则来源 | 人观察到问题后手写 | Agent 自己从反馈中提炼 |
| 存储位置 | CLAUDE.md（单文件） | 多个 Skill 文件 + 记忆数据库 |
| 触发改进 | 人记得要加规则才会加 | 每次使用后自动评估 |
| 跨项目迁移 | 需要手动复制 CLAUDE.md | Skill 全局生效，所有项目共享 |
| 改进速度 | 取决于人的勤快程度 | 持续自动，不会懒 |

> — Clippings/papers/Hermes Agent 从入门到精通.pdf, §03

## 自改进的天花板

自改进 Agent 的天花板不在技术，在反馈信号：

**关键假设**：Agent 能判断自己的改进是好是坏。

- **人在场给反馈**：循环有效（你说"不对"，它调整）→ 带监督的改进
- **人不在场**：Agent 只能用自己的评估标准（"更快更准"不等于"更对"）

Agent 不知道自己不知道什么。自改进让 Agent 在已知方向上越跑越快，但方向本身还是得人来定。

> — Clippings/papers/Hermes Agent 从入门到精通.pdf, §17

## 应用场景

| 场景 | 学习循环的价值 |
|-----|---------------|
| **个人知识助手** | 跨会话积累，不用每次重新解释背景 |
| **代码审查** | 从反馈中学到你的代码规范偏好 |
| **内容创作** | 写作风格 Skill 从你的修改中自动积累 |
| **长期调研项目** | 排除的方案不会被重新推荐，已确认的信息不用重新查证 |

记忆的价值和任务的持续时间成正比。任务越长、上下文越复杂，学习循环带来的效率增益越大。

> — Clippings/papers/Hermes Agent 从入门到精通.pdf, §12
