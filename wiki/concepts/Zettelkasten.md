# Zettelkasten

> 德国社会学家 Niklas Luhmann 发明的原子化笔记方法：每条笔记只包含一个想法，用链接编织知识网络

## 核心原则

| 原则 | 说明 |
|------|------|
| **原子化** | 每条笔记只包含一个完整想法 |
| **用自己的话** | 重写而非复制，强迫理解 |
| **密集链接** | 用 [[双向链接]] 连接相关笔记 |
| **自下而上** | 不预设分类，结构在使用中自然涌现 |

## 核心回答的问题

「这个想法和我已知的知识有什么联系？」

## 在 Obsidian 中的实践

- 每条原子笔记一个 .md 文件
- 通过 `[[链接]]` 建立笔记间关系
- 不依赖文件夹层级，依赖链接网络
- 笔记量增长后，通过 MOC（内容地图）导航

> — [[Clippings/articles/Obsidian本地知识库搭建：从入门到第二大脑.md]], L60-70

## 与 PARA、MOC 的关系

融合模型中 Zettelkasten 的角色：
- **Zettelkasten = 洞察引擎**：原子化记录每次思考
- **PARA = 行动枢纽**：管理任务和项目
- **MOC = 导航层**：为 Zettelkasten 的链接网络提供入口
